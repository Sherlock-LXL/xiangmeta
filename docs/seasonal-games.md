# 四季游乐

入口：侧栏「四季游乐」，或靠近四岛上的游乐摊位按 V。支持桌面键盘和触屏。

| 季节 | 体验 | 操作 |
| --- | --- | --- |
| 春 | 山地摩托；沿现有登山主路和视觉捷径绕圈 | WASD 油门、倒车与转向；空格刹车；Shift 冲刺 |
| 夏 | 快艇；夏岛外海水上赛道 | WASD 油门、倒车与舵向；空格刹车；Shift 加速 |
| 秋 | 滑翔伞；群岛上空的立体航线 | W 俯冲、S 抬升、AD 倾斜转弯、空格空气刹车；金色气流补充高度 |
| 冬 | 方块消除、贪吃蛇、打砖块、2048、翻牌配对 | 每款游戏显示操作提示；键盘、按钮或画布触屏操作 |

计时挑战有三秒倒计时，按顺序正向穿过全部信标，完成两圈。R 复位到上一个信标，正式开始后每次加五秒；休闲模式不显示路线、不判圈、不计罚时。P / Esc 或屏幕暂停按钮可暂停、复位和退出；切走窗口时自动暂停。退出载具后返回所在摊位的安全入口。

冲刺消耗蓄能，耗尽后需松开按钮并恢复至少四分之一再启动；松开冲刺会自然减速。打开原世界面板会暂停计时，关闭后继续；游戏中的 P 优先用于暂停。计时按实际经过的秒数计算，物理碰撞仍用短步积分。驾驶时动物保持活动并对靠近的载具让路。

成绩按赛道长度和参考均速设置金、银、铜三级；目标时间显示在驾驶 HUD，依次配烟花、星芒、光点。最高成绩使用 `xiangmeta.games.v1.race.<season>.<courseVersion>` 和 `xiangmeta.games.v1.arcade.<id>` 存入本浏览器 localStorage。竞速记录取最短总用时，小游戏取最高得分。存储失败仍可游戏，结算会说明未保存。

## 实现边界

- `shared/seasonal-games.mjs`：赛道、扫掠信标判定、计时、成绩和载具物理，无渲染依赖。
- `shared/arcade.mjs`：五款小游戏状态机；`src/world/arcade-room.ts` 按需加载，负责 Canvas 绘制与输入。
- `src/world/seasonal-games.ts`：摊位安全放置、游戏生命周期、追随镜头、交互、HUD 与特效。
- `src/world/game-models.ts`：沿用原世界材质和建筑构件的程序化载具、骑手与摊位。
- `World` 仅增加生命周期、输入互斥和相机切换；保持中央枢纽、原始四岛、地形与展览模块。
- 摩托使用共享行走碰撞、短步积分与地形高度；快艇受近岸安全边界约束；滑翔伞撞到地面或建筑、飞出世界范围时复位。所有模式都可手动复位。
- 临时赛道、尾迹和结算粒子在退出时释放；不增加图片下载、外部服务或第三方运行依赖。

人物自动跨越不高于 0.48 m 的小台阶，骑乘可跨越 0.55 m。骑乘支持岛屿、连接桥和中央枢纽的连续地面，依旧拒绝无支撑的海面和穿墙。下骑后动物会把新位置作为活动中心。

## 验证

`npm test` 覆盖移动、碰撞、正逆向信标、完整两圈、存储容错、各载具控制及五款小游戏核心规则。

构建并启动预览后运行 `npm run test:games`。默认预览为 `http://127.0.0.1:4191/world/`，测试截图和场景数据写入 `/private/tmp/seasonal-review`。可用 `GAME_ORIGIN`、`GAME_ARTIFACTS`、`GAME_ENGINE=webkit`、`GAME_TOUCH=1` 切换环境。浏览器检查使用低画质减轻自动化环境的 WebGL 负担；真实指针和键盘操作验证入口、驾驶、暂停、复位、退出及每款街机。额外用浏览器导出的真实碰撞体验证山路完整绕圈。

`npm run test:game-experience` 用真实按键完成快艇与滑翔伞两圈，验证等级结算、重开、P / Esc、原世界面板暂停、小游戏暂停与重启、翻牌完整胜利及刷新后成绩保留。`npm run test:mounts` 骑北极熊从冬岛穿过桥梁与枢纽抵达春岛，验证安全下骑和新的活动中心。Chromium 触屏检查包含双指同时油门与转向，以及单独松开转向后继续加速。
